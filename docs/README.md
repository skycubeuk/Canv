# Canv user guide

Welcome. This guide is written for writers — no developer background assumed.
If you are a developer, the repo-root [README](../README.md) covers
contributing, profiles, and the build/release workflow.

## Pages

1. [**Getting started**](getting-started.md) — install, pick a profile, add an
   API key, write your first sentence, run your first agent.
2. [**The editor**](the-editor.md) — typing, formatting, preview, the floating
   toolbar, the document agent menu, themes, fonts.
3. [**Profiles and agents**](profiles-and-agents.md) — what a profile is, the
   bundled profiles, custom instructions, per-agent model overrides.
4. [**Results and applying**](results-and-applying.md) — the results panel,
   streaming, before/after diff, Apply, history.
5. [**Chat and tools**](chat-and-tools.md) — the chat panel, what tools the
   chat agent can use, approval flow, todo card.
6. [**Workspaces and files**](workspaces-and-files.md) — the file tree, tabs,
   command palette, pinning files for context, remote (SSH) workspaces.
7. [**Settings and data**](settings-and-data.md) — settings tab, where data
   lives on disk, backup, migration from older versions, lint rules.
8. [**Troubleshooting**](troubleshooting.md) — first-launch warnings, common
   errors, where to find logs.

## Quick conventions

- Screenshots show the **Fiction profile** unless otherwise noted.
- Dark theme is the default in screenshots; light theme works the same.
- Keyboard shortcuts use macOS keys; Linux/Windows use **Ctrl** in place of
  **⌘**.
