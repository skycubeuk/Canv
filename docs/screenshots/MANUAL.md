# Manual screenshot capture list

Some screens cannot be reached via the Playwright Electron driver and
require a human contributor with the app running locally.

## Pending shots

| Shot | Page | Why deferred | How to take it |
|------|------|-------------|----------------|
| `profiles-and-agents/edit-system-prompt.png` | profiles-and-agents.md | No in-app system prompt editor exists; prompts live in YAML files only. | When an in-app editor ships, add a `data-testid="system-prompt-editor"` to its container and add the capture to `captureProfilesAndAgents`. |
| `chat-and-tools/chat-with-message.png` | chat-and-tools.md | Requires a real API key; shows a live message exchange in the chat panel. | 1. Add `ANTHROPIC_API_KEY=<key>` to `.env.screenshots`. 2. Add automation to `captureChatAndTools` in `scripts/screenshots.mjs`: send a message, wait for the response bubble, then call `capture(helpers, 'chat-and-tools/chat-with-message')`. |
| `chat-and-tools/tool-chip.png` | chat-and-tools.md | Requires a real API key — shows a `read_file` or `list_dir` chip after a workspace query. | With API key present, ask the chat "What files are in my workspace?" and wait for the assistant response bubble containing a `.lucide` chip, then capture. |
| `chat-and-tools/approval-card-pending.png` | chat-and-tools.md | Approval cards are driven by live React turn state (a `Map`) — cannot be seeded via localStorage. | With API key, ask "Create a file called notes.md" in chat. Wait for the approval card (`button:has-text("Approve")`), then capture before clicking. |
| `chat-and-tools/approval-card-approved.png` | chat-and-tools.md | Requires the pending approval shot above, then clicking Approve. | Immediately after capturing `approval-card-pending.png`, click the Approve button and wait for the `✓ approved` status text, then capture. |
| `chat-and-tools/todo-card.png` | chat-and-tools.md | Requires a real API key — the `set_todos` tool is only called during a multi-step chat turn. | Ask "Plan and then create three short markdown files about cats". When the todo card appears (`[data-testid="todo-card"]`), capture before the plan is executed. |
| `chat-and-tools/tool-budget-reached.png` | chat-and-tools.md | Requires a real API key and a task that exhausts the tool budget. | Lower `chatToolBudget` to 2 in Settings, then ask the chat to do a multi-step task. When the budget note appears (synthetic message containing "tool budget"), capture. |
| `workspaces-and-files/workspace-on-disk.png` | workspaces-and-files.md | Requires a desktop file manager (Finder on macOS, Explorer on Windows, Nautilus on Linux) — not available in the headless CI environment. | Open your workspace folder in your system file manager so both the `.canv/` folder and a few `.md` files are visible. Take a screenshot of that window and save it as `docs/screenshots/workspaces-and-files/workspace-on-disk.png`. |
| `troubleshooting/gatekeeper.png` | troubleshooting.md | macOS-only native OS dialog — requires a real Mac with an unsigned build of Canv. | 1. Download or build an unsigned Canv `.dmg`. 2. Mount it, drag `Canv.app` to a fresh location. 3. Double-click `Canv.app` without right-clicking first — macOS shows the "cannot be opened because Apple cannot verify it" Gatekeeper dialog. 4. Take a screenshot of that dialog and save it as `docs/screenshots/troubleshooting/gatekeeper.png`. |
| `troubleshooting/smartscreen.png` | troubleshooting.md | Windows-only native OS dialog — requires a real Windows machine with an unsigned Canv installer. | 1. Download or build an unsigned Canv `.exe` installer. 2. Run it on a Windows machine with SmartScreen enabled. 3. When the "Windows protected your PC" dialog appears, take a screenshot and save it as `docs/screenshots/troubleshooting/smartscreen.png`. |
| `troubleshooting/api-error-banner.png` | troubleshooting.md | Requires a network call to the live Anthropic API with an invalid key — not available in a sandboxed screenshot environment without real API access. | 1. Add `ANTHROPIC_API_KEY=sk-ant-invalid` to `.env.screenshots`. 2. Open the canonical fixture and select some text. 3. Run any Grammar or Rewrite agent. 4. After the error banner appears in the results panel (red box containing "Anthropic 401: …"), take a screenshot of the results panel region and save it as `docs/screenshots/troubleshooting/api-error-banner.png`. |
